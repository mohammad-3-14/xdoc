# آشنایی با شبکه‌های کامپیوتری، اجزای اصلی و نقش Host، Server، Workstation و Client

شبکه‌های کامپیوتری پایه‌ی ارتباط میان دستگاه‌ها، کاربران و سرویس‌های دیجیتال هستند. زمانی که چند دستگاه بتوانند از طریق یک بستر ارتباطی با یکدیگر داده ردوبدل کنند یا منابع مشترکی را در اختیار هم قرار دهند، یک شبکه شکل گرفته است.

در این مقاله ابتدا مفهوم شبکه را تعریف می‌کنیم، سپس دلایل استفاده از شبکه را بررسی می‌کنیم و در ادامه با مهم‌ترین اجزای یک شبکه، از جمله **Host**، **Server**، **Workstation** و **Client** آشنا می‌شویم.

## شبکه کامپیوتری چیست؟

یک شبکه کامپیوتری مجموعه‌ای از دو یا چند دستگاه متصل به یکدیگر است که می‌توانند با هم ارتباط برقرار کنند، اطلاعات ردوبدل کنند و از منابع مشترک استفاده کنند.

تعریف ساده‌ی شبکه را می‌توان به این شکل بیان کرد:

> شبکه، گروهی از سیستم‌ها یا دستگاه‌های متصل به یکدیگر است که امکان ارتباط و اشتراک‌گذاری منابع را فراهم می‌کنند.

این دستگاه‌ها می‌توانند شامل موارد زیر باشند:

- کامپیوترهای رومیزی
- لپ‌تاپ‌ها
- سرورها
- روترها
- سوئیچ‌ها
- تلفن‌های هوشمند
- چاپگرهای شبکه
- دوربین‌های تحت شبکه
- تجهیزات اینترنت اشیا یا IoT

برای مثال، اگر دو کامپیوتر و یک چاپگر به یک سوئیچ متصل شوند و هر دو کامپیوتر بتوانند از چاپگر استفاده کنند، یک شبکه‌ی ساده ایجاد شده است.

```text
Computer 1 ───┐
              ├── Switch ─── Network Printer
Computer 2 ───┘
```

در این مثال، سوئیچ ارتباط میان دستگاه‌ها را برقرار می‌کند و چاپگر به‌عنوان یک منبع مشترک در اختیار هر دو کامپیوتر قرار می‌گیرد.

## چرا از شبکه استفاده می‌کنیم؟

شبکه فقط برای اتصال چند دستگاه به یکدیگر ساخته نمی‌شود. هدف اصلی آن ساده‌تر کردن ارتباط، اشتراک منابع، مدیریت متمرکز و افزایش بهره‌وری است.

### حذف محدودیت‌های جغرافیایی

شبکه‌ها به کاربران اجازه می‌دهند بدون نیاز به حضور در یک مکان مشترک با یکدیگر ارتباط برقرار کنند.

برای مثال:

- کارمندان یک شرکت می‌توانند از شعب مختلف به سامانه‌ی مرکزی متصل شوند.
- یک مدیر سیستم می‌تواند از راه دور سرورها را مدیریت کند.
- کاربران از طریق اینترنت به سرویس‌هایی در کشورهای دیگر دسترسی پیدا می‌کنند.
- اعضای یک تیم می‌توانند از شهرهای مختلف روی یک پروژه مشترک کار کنند.

هرچه مقیاس شبکه بزرگ‌تر شود، فاصله‌ی جغرافیایی دستگاه‌ها نیز می‌تواند بیشتر باشد.

### صرفه‌جویی در زمان و هزینه

با استفاده از شبکه، لازم نیست برای هر کاربر یک منبع جداگانه تهیه شود.

برای مثال، به‌جای خرید یک چاپگر برای هر کارمند، می‌توان یک یا چند چاپگر شبکه را میان همه‌ی کاربران به اشتراک گذاشت.

همچنین انتقال فایل از طریق شبکه بسیار سریع‌تر و ساده‌تر از جابه‌جایی فایل با فلش یا هارد اکسترنال است.

### اشتراک‌گذاری منابع

یکی از اصلی‌ترین دلایل ساخت شبکه، اشتراک‌گذاری منابع است.

منابع قابل اشتراک می‌توانند شامل موارد زیر باشند:

- فایل‌ها و پوشه‌ها
- چاپگرها
- اتصال اینترنت
- فضای ذخیره‌سازی
- نرم‌افزارها
- پایگاه‌های داده
- سرویس‌های ایمیل
- توان پردازشی
- دستگاه‌های پشتیبان‌گیری

برای نمونه، کاربران یک شرکت می‌توانند فایل‌های خود را روی یک File Server مرکزی ذخیره کنند و از چند سیستم مختلف به آن‌ها دسترسی داشته باشند.

### افزایش امنیت و کنترل

در شبکه‌های سازمانی، دسترسی کاربران و دستگاه‌ها می‌تواند به‌صورت متمرکز مدیریت شود.

برای مثال، مدیر شبکه می‌تواند مشخص کند:

- چه کاربری به چه فایل‌هایی دسترسی داشته باشد.
- چه دستگاهی اجازه‌ی اتصال به شبکه را داشته باشد.
- کدام کاربران بتوانند از اینترنت استفاده کنند.
- چه سرویس‌هایی از خارج شبکه قابل دسترسی باشند.
- چه فعالیت‌هایی ثبت و مانیتور شوند.

> شبکه به‌خودی‌خود امنیت ایجاد نمی‌کند. امنیت زمانی افزایش می‌یابد که کنترل دسترسی، احراز هویت، فایروال، رمزنگاری و مانیتورینگ به‌درستی پیاده‌سازی شده باشند.

## اجزای متداول شبکه

یک شبکه از چند دسته جزء اصلی تشکیل می‌شود. در این مبحث سه جزء مهم بررسی می‌شوند:

1. میزبان‌ها یا Hosts
2. ایستگاه‌های کاری یا Workstations
3. سرورها یا Servers

در عمل، تجهیزات دیگری مانند سوئیچ، روتر، فایروال، Access Point و کابل شبکه نیز وجود دارند؛ اما تمرکز این بخش روی دستگاه‌هایی است که مستقیماً سرویس ارائه می‌کنند یا از سرویس‌ها استفاده می‌کنند.

## Host یا میزبان چیست؟

در شبکه، به هر دستگاهی که دارای آدرس IP باشد و بتواند داده ارسال یا دریافت کند، **Host** گفته می‌شود.

نمونه‌های Host عبارت‌اند از:

- کامپیوتر
- لپ‌تاپ
- سرور
- روتر
- تلفن هوشمند
- چاپگر شبکه
- دوربین تحت شبکه
- برخی سوئیچ‌های مدیریتی
- ماشین مجازی
- دستگاه‌های اینترنت اشیا

برای اینکه یک دستگاه در شبکه قابل شناسایی و قابل ارتباط باشد، معمولاً باید یک آدرس شبکه داشته باشد. در شبکه‌های مبتنی بر TCP/IP، این آدرس همان IP Address است.

برای مثال:

```text
Computer: 192.168.1.10
Server:   192.168.1.20
Printer:  192.168.1.30
Router:   192.168.1.1
```

هرکدام از این دستگاه‌ها یک Host محسوب می‌شوند، زیرا در شبکه آدرس دارند و می‌توانند داده ارسال یا دریافت کنند.

> هر Client یا Server می‌تواند یک Host باشد، اما هر Host الزاماً Client یا Server نیست. برای مثال، یک روتر Host محسوب می‌شود، ولی معمولاً آن را Client معمولی یا Server کاربردی در نظر نمی‌گیریم.

## انواع Host

Hostها را می‌توان بر اساس نقشی که در شبکه دارند به چند گروه تقسیم کرد.

### Client Host

Client Host دستگاهی است که از یک Server درخواست سرویس می‌کند.

نمونه‌ها:

- کامپیوتر شخصی
- لپ‌تاپ
- تلفن هوشمند
- تبلت

برای مثال، زمانی که مرورگر شما یک صفحه‌ی وب را از یک Web Server دریافت می‌کند، سیستم شما در نقش Client Host قرار دارد.

### Server Host

Server Host دستگاهی است که به Clientها سرویس ارائه می‌دهد.

نمونه‌ها:

- Web Server
- Database Server
- File Server
- Mail Server

سرور معمولاً منتظر درخواست Clientها می‌ماند، درخواست را پردازش می‌کند و پاسخ مناسب را برمی‌گرداند.

### Networking Host

برخی تجهیزات شبکه نیز دارای آدرس IP هستند و می‌توانند به‌عنوان Host شناخته شوند.

نمونه‌ها:

- Router
- Managed Switch
- Firewall
- Wireless Access Point

این تجهیزات معمولاً برای مدیریت، مانیتورینگ، پیکربندی یا مسیریابی دارای IP Address هستند.

> سوئیچ‌های ساده و غیرمدیریتی ممکن است برای انجام وظیفه‌ی اصلی خود به IP نیاز نداشته باشند. در مقابل، سوئیچ مدیریتی معمولاً برای دسترسی مدیریتی دارای IP Address است.

### Virtual Host

یک ماشین مجازی که روی یک سرور فیزیکی اجرا می‌شود و IP جداگانه دارد نیز یک Host مستقل محسوب می‌شود.

برای مثال، یک سرور فیزیکی ممکن است میزبان چند ماشین مجازی باشد:

```text
Physical Server
├── VM 1: 192.168.1.101
├── VM 2: 192.168.1.102
└── VM 3: 192.168.1.103
```

با وجود اینکه هر سه ماشین مجازی از سخت‌افزار مشترک استفاده می‌کنند، در شبکه هرکدام می‌توانند به‌عنوان یک Host مستقل دیده شوند.

## Server یا سرور چیست؟

سرور یک کامپیوتر یا سیستم نرم‌افزاری است که منابع یا خدماتی را در اختیار دستگاه‌های دیگر قرار می‌دهد.

سرورها معمولاً قدرت پردازشی، حافظه، فضای ذخیره‌سازی و قابلیت اطمینان بیشتری نسبت به سیستم‌های معمولی دارند، اما «سرور» بودن فقط به سخت‌افزار قدرتمند وابسته نیست.

یک لپ‌تاپ نیز می‌تواند نرم‌افزار سرور اجرا کند و به دستگاه‌های دیگر سرویس دهد؛ هرچند برای محیط‌های حرفه‌ای، معمولاً از سخت‌افزار و سیستم‌عامل مناسب سرور استفاده می‌شود.

سرورها اغلب برای انجام یک یا چند وظیفه‌ی مشخص در شبکه پیکربندی می‌شوند.

### ویژگی‌های رایج سرورها

سرورها معمولاً دارای ویژگی‌های زیر هستند:

- روشن بودن طولانی‌مدت یا دائمی
- پاسخ‌گویی هم‌زمان به چند Client
- ظرفیت پردازشی و حافظه‌ی بیشتر
- فضای ذخیره‌سازی قابل توسعه
- امکان پشتیبان‌گیری منظم
- دسترسی و مدیریت از راه دور
- کنترل دسترسی کاربران
- ثبت رخدادها و مانیتورینگ
- افزونگی در دیسک، برق یا شبکه در محیط‌های حرفه‌ای

> سرور الزاماً یک دستگاه فیزیکی مستقل نیست. سرور می‌تواند فیزیکی، مجازی، کانتینری یا حتی یک نرم‌افزار در حال اجرا روی سیستم معمولی باشد.

## انواع رایج سرور

### File Server

File Server برای ذخیره‌سازی و ارائه‌ی فایل‌ها در شبکه استفاده می‌شود.

کاربران می‌توانند فایل‌های خود را روی سرور ذخیره کنند و بر اساس سطح دسترسی به پوشه‌های مشترک متصل شوند.

کاربردهای رایج:

- ذخیره‌ی اسناد سازمانی
- اشتراک فایل میان تیم‌ها
- مدیریت مجوزهای دسترسی
- پشتیبان‌گیری متمرکز

پروتکل‌های متداول:

- SMB
- NFS
- FTP
- SFTP

### Mail Server

Mail Server ارسال، دریافت و نگهداری ایمیل‌ها را مدیریت می‌کند.

پروتکل‌های مرتبط:

- SMTP برای ارسال ایمیل
- IMAP برای دریافت و همگام‌سازی ایمیل
- POP3 برای دریافت ایمیل

در یک سازمان، Mail Server می‌تواند صندوق‌های ایمیل کاربران، قوانین ضداسپم و مسیر ارسال پیام‌ها را مدیریت کند.

### Print Server

Print Server چاپگرهای شبکه و درخواست‌های چاپ را مدیریت می‌کند.

وظایف آن می‌تواند شامل موارد زیر باشد:

- ایجاد صف چاپ
- مدیریت چند چاپگر
- کنترل دسترسی کاربران
- نصب و ارائه‌ی درایور چاپگر
- ثبت وضعیت و خطاهای چاپ

### Web Server

Web Server درخواست‌های HTTP یا HTTPS را دریافت می‌کند و محتوای وب را به Client تحویل می‌دهد.

نمونه‌های معروف نرم‌افزار Web Server:

- Nginx
- Apache HTTP Server
- Microsoft IIS
- Caddy

روند ساده‌ی ارتباط:

```text
Browser → HTTP Request → Web Server
Browser ← HTTP Response ← Web Server
```

مرورگر در این ارتباط Client و سرویس Nginx یا Apache در نقش Server است.

### Database Server

Database Server داده‌های ساختاریافته را ذخیره و مدیریت می‌کند.

نمونه‌ها:

- MySQL
- PostgreSQL
- Microsoft SQL Server
- Oracle Database
- MongoDB

برنامه‌های کاربردی برای ثبت، خواندن، ویرایش یا حذف داده‌ها به Database Server درخواست ارسال می‌کنند.

### Application Server

Application Server منطق اصلی یک برنامه را اجرا می‌کند.

برای مثال، در یک وب‌سایت فروشگاهی ممکن است ساختار زیر وجود داشته باشد:

```text
User Browser
     │
     ▼
Web Server
     │
     ▼
Application Server
     │
     ▼
Database Server
```

در این معماری، هر سرور وظیفه‌ی مشخصی دارد.

## Workstation یا ایستگاه کاری چیست؟

Workstation یک کامپیوتر قدرتمند است که برای اجرای نرم‌افزارهای تخصصی و پردازش‌های سنگین طراحی شده است.

این سیستم‌ها معمولاً توسط کاربران حرفه‌ای استفاده می‌شوند، مانند:

- مهندسان
- طراحان گرافیک
- تدوین‌گران
- متخصصان سه‌بعدی
- دانشمندان داده
- برنامه‌نویسان
- توسعه‌دهندگان نرم‌افزار

Workstation معمولاً از نظر سخت‌افزار از یک کامپیوتر اداری معمولی قوی‌تر است.

ویژگی‌های احتمالی آن عبارت‌اند از:

- پردازنده‌ی قدرتمند
- حافظه‌ی RAM زیاد
- کارت گرافیک حرفه‌ای
- فضای ذخیره‌سازی سریع
- امکان اتصال چند نمایشگر
- پایداری بالا در پردازش‌های طولانی

### کاربردهای متداول Workstation

#### مدل‌سازی سه‌بعدی و انیمیشن

نرم‌افزارهای رایج:

- Maya
- Blender
- AutoCAD

این برنامه‌ها برای طراحی، مدل‌سازی و رندرینگ به منابع پردازشی زیادی نیاز دارند.

#### تحلیل داده و محاسبات علمی

نرم‌افزارها و ابزارهای رایج:

- MATLAB
- TensorFlow
- Python
- ابزارهای محاسبات عددی

#### برنامه‌نویسی و توسعه‌ی نرم‌افزار

یک Workstation ممکن است برای کارهای زیر استفاده شود:

- اجرای چند ماشین مجازی
- ساخت پروژه‌های بزرگ
- کامپایل نرم‌افزار
- اجرای محیط‌های توسعه
- اجرای کانتینرها
- تست سرویس‌های متعدد

#### تدوین و رندر ویدیو

نرم‌افزارهای رایج:

- Adobe Premiere Pro
- DaVinci Resolve

این کارها معمولاً به CPU، GPU، RAM و فضای ذخیره‌سازی سریع نیاز دارند.

> Workstation یک نقش سخت‌افزاری یا کاربردی است، اما Client یک نقش شبکه‌ای است. یک Workstation می‌تواند در شبکه به‌عنوان Client عمل کند و از سرورها سرویس بگیرد.

## Client یا کلاینت چیست؟

Client دستگاه یا نرم‌افزاری است که یک سرویس را از Server درخواست و مصرف می‌کند.

Client معمولاً آغازکننده‌ی ارتباط است. برای مثال، وقتی کاربر آدرس یک سایت را در مرورگر وارد می‌کند، مرورگر یک درخواست به Web Server ارسال می‌کند.

```text
Client → Request → Server
Client ← Response ← Server
```

Clientها برای دریافت منابعی مانند موارد زیر به سرورها وابسته‌اند:

- فایل
- صفحه‌ی وب
- ایمیل
- پایگاه داده
- نرم‌افزار
- احراز هویت
- فضای ذخیره‌سازی
- سرویس چاپ

Clientها معمولاً برای تعامل مستقیم با کاربر بهینه شده‌اند، در حالی که Serverها برای ارائه‌ی سرویس به تعداد زیادی Client بهینه می‌شوند.

## انواع رایج Client

### Desktop Client

کامپیوترهای رومیزی که سیستم‌عامل‌هایی مانند Windows، Linux یا macOS اجرا می‌کنند می‌توانند Client باشند.

برای مثال، یک کامپیوتر کارمند ممکن است:

- از File Server فایل دریافت کند.
- از Print Server برای چاپ استفاده کند.
- به Mail Server متصل شود.
- از Web Server صفحات وب دریافت کند.

### Laptop Client

لپ‌تاپ‌ها Clientهای قابل حمل هستند که معمولاً از طریق شبکه‌ی سیمی یا بی‌سیم به سرویس‌ها متصل می‌شوند.

### Thin Client

Thin Client یک سیستم سبک است که بخش زیادی از پردازش و ذخیره‌سازی را به Server واگذار می‌کند.

در این مدل، دستگاه کاربر سخت‌افزار محدودی دارد و برنامه‌ها یا دسکتاپ اصلی روی سرور اجرا می‌شوند.

نمونه‌ی کاربرد:

- محیط‌های VDI
- Remote Desktop
- سیستم‌های اداری متمرکز
- پایانه‌های بانکی یا سازمانی

### Smart Device

تلفن‌های هوشمند، تبلت‌ها و برخی تجهیزات IoT نیز می‌توانند به‌عنوان Client عمل کنند.

برای مثال:

- تلفن همراه به Mail Server متصل می‌شود.
- تلویزیون هوشمند از Streaming Server ویدیو دریافت می‌کند.
- دوربین IoT اطلاعات خود را به Cloud Server ارسال می‌کند.

## تفاوت Host، Client، Server و Workstation

این چهار اصطلاح گاهی با هم اشتباه گرفته می‌شوند، اما هرکدام مفهوم متفاوتی دارند.

| اصطلاح | تعریف | معیار اصلی |
|---|---|---|
| Host | هر دستگاه دارای آدرس شبکه که داده ارسال یا دریافت می‌کند | حضور و قابلیت ارتباط در شبکه |
| Client | دستگاه یا نرم‌افزاری که سرویس درخواست می‌کند | درخواست‌کننده‌ی سرویس |
| Server | دستگاه یا نرم‌افزاری که سرویس ارائه می‌دهد | ارائه‌دهنده‌ی سرویس |
| Workstation | کامپیوتر قدرتمند برای کارهای تخصصی | توان سخت‌افزاری و نوع کاربرد |

یک دستگاه می‌تواند هم‌زمان چند نقش داشته باشد.

برای مثال، کامپیوتر یک برنامه‌نویس می‌تواند:

- یک **Host** باشد، چون IP Address دارد.
- یک **Workstation** باشد، چون سخت‌افزار قدرتمند دارد.
- یک **Client** باشد، چون به Git Server یا Database Server متصل می‌شود.
- یک **Server** نیز باشد، اگر روی آن یک Web Server محلی اجرا شود.

> Client و Server نقش‌های ارتباطی هستند، نه الزاماً نام نوع سخت‌افزار. نقش یک دستگاه می‌تواند با توجه به نوع ارتباط تغییر کند.

## مدل Client-Server

در مدل Client-Server، یک یا چند سرور منابع و سرویس‌ها را به Clientها ارائه می‌کنند.

```text
Client 1 ──┐
Client 2 ──┼── Server
Client 3 ──┘
```

مزایای این مدل:

- مدیریت متمرکز
- کنترل بهتر دسترسی‌ها
- پشتیبان‌گیری ساده‌تر
- نگهداری متمرکز اطلاعات
- امکان سرویس‌دهی به تعداد زیادی کاربر
- مانیتورینگ و ثبت رخدادها

معایب احتمالی:

- وابستگی Clientها به Server
- هزینه‌ی راه‌اندازی و نگهداری
- نیاز به مدیریت تخصصی
- ایجاد نقطه‌ی خرابی واحد در صورت نبود افزونگی

## نمونه‌ی کامل از یک شبکه‌ی کوچک

فرض کنید یک شرکت کوچک دارای تجهیزات زیر است:

- ۱۰ کامپیوتر کارمندان
- یک File Server
- یک Web Server داخلی
- یک چاپگر شبکه
- یک سوئیچ
- یک روتر
- چند تلفن همراه

نقش دستگاه‌ها:

| دستگاه | Host | Client | Server | Workstation |
|---|---:|---:|---:|---:|
| کامپیوتر کارمند | بله | بله | معمولاً خیر | ممکن است |
| File Server | بله | گاهی | بله | خیر |
| Web Server | بله | گاهی | بله | خیر |
| چاپگر شبکه | بله | معمولاً خیر | ارائه‌دهنده‌ی سرویس چاپ | خیر |
| روتر | بله | خیر | سرویس شبکه‌ای | خیر |
| تلفن همراه | بله | بله | معمولاً خیر | خیر |

در این شبکه، کامپیوترها از File Server فایل دریافت می‌کنند، از چاپگر شبکه استفاده می‌کنند و برای دسترسی به اینترنت از روتر عبور می‌کنند.

## بررسی Host و IP در سیستم‌عامل

در Linux می‌توان آدرس‌های شبکه را با دستور زیر مشاهده کرد:

```bash
ip address
```

نسخه‌ی کوتاه‌تر:

```bash
ip addr
```

برای مشاهده‌ی آدرس‌های IPv4:

```bash
ip -4 addr
```

نمونه‌ی خروجی:

```text
2: enp3s0: <BROADCAST,MULTICAST,UP,LOWER_UP>
    inet 192.168.1.25/24 brd 192.168.1.255 scope global enp3s0
```

در این مثال، سیستم دارای IP زیر است:

```text
192.168.1.25
```

بنابراین این دستگاه در شبکه یک Host محسوب می‌شود.

در Windows می‌توان از دستور زیر استفاده کرد:

```powershell
ipconfig
```

برای مشاهده‌ی جزئیات بیشتر:

```powershell
ipconfig /all
```

## نکات مهم و قابل اشتباه

> داشتن سخت‌افزار قدرتمند به‌تنهایی یک سیستم را Server نمی‌کند. زمانی که سیستم به دستگاه‌های دیگر سرویس ارائه دهد، نقش Server دارد.

> هر Server یک Host است، اما هر Host یک Server نیست.

> Workstation معمولاً نوعی کامپیوتر قدرتمند است؛ Client نقشی است که دستگاه در ارتباط شبکه‌ای دارد.

> یک دستگاه می‌تواند در یک ارتباط Client و در ارتباطی دیگر Server باشد.

> آدرس IP برای شناسایی Host در شبکه‌های TCP/IP استفاده می‌شود، اما ارتباط شبکه علاوه بر IP به مواردی مانند Subnet Mask، Gateway، MAC Address و پروتکل‌ها نیز وابسته است.

## جمع‌بندی

شبکه مجموعه‌ای از دستگاه‌های متصل به یکدیگر است که می‌توانند داده و منابع را به اشتراک بگذارند. استفاده از شبکه باعث کاهش محدودیت جغرافیایی، صرفه‌جویی در زمان و هزینه، اشتراک منابع و مدیریت بهتر امنیت می‌شود.

در یک شبکه:

- **Host** هر دستگاه قابل شناسایی و قابل ارتباط است.
- **Server** سرویس و منابع ارائه می‌دهد.
- **Client** سرویس‌ها را درخواست و مصرف می‌کند.
- **Workstation** یک کامپیوتر قدرتمند برای کارهای تخصصی است.

درک تفاوت این مفاهیم، پایه‌ی یادگیری موضوعات پیشرفته‌تر شبکه مانند مدل Client-Server، آدرس‌دهی IP، تجهیزات شبکه، پروتکل‌ها، مجازی‌سازی و امنیت شبکه است.

# کشف شبکه و اسکن با Nmap

## ۱. کشف و اسکن با Nmap

یک مهاجم می‌خواهد توپولوژی شبکهٔ هدف را بشناسد:
- اتصال اینترنتی، شبکه‌های پیرامونی
- شبکهٔ داخلی (با دسترسی از مودم یا Access Point بی‌سیم)
- کشف توپولوژی می‌تواند آسیب‌پذیری‌ها را آشکار کند (یا حداقل معماری شبکه را فاش سازد)

Nmap می‌تواند برای **نقشه‌برداری شبکه و اسکن پورت** استفاده شود:
- نوشته‌شده توسط Fyodor و تیم توسعهٔ Nmap
- برای Linux، macOS و Windows در دسترس است

---

## ۲. Sweeping برای نقشه‌برداری شبکه

- **Sweeping** گذر از فضای آدرس برای شناسایی میزبان‌های فعال در شبکه است
- مهاجم یک ICMP Echo Request به بازه‌ای از آدرس‌های IP ارسال می‌کند:
  - اگر پاسخی برگشت، آن آدرس توسط یک سیستم هدف در حال استفاده است
  - اگر پاسخی نبود، آن آدرس در حال استفاده نیست یا فیلترینگ شبکه وجود دارد
- به‌طور پیش‌فرض، Nmap پیش از اسکن پورت، هر آدرس هدف را با استفاده از **host discovery** بررسی می‌کند
  - می‌توان برای دقت بیشتر از آن صرف‌نظر کرد (`-Pn`) اما اسکن را کند می‌کند
- برای بهترین نتیجه، Nmap را به‌عنوان root اجرا کنید

---

## ۳. Host Discovery با Nmap

```bash
~$ sudo nmap -sn 192.168.1.1-254

Starting Nmap 7.60 ( https://nmap.org ) at 2021-07-03 14:58 UTC
Nmap scan report for 192.168.1.1
Host is up (0.0081s latency).
```

> **نکتهٔ آزمون:** گزینهٔ `-sn` اسکن پورت را غیرفعال می‌کند و فقط Host Discovery را انجام می‌دهد؛ اگر روی همان LAN باشید از ARP استفاده می‌شود.

---

## ۴. Port Scanning

- Port Scanner‌ها ابزاری ضروری برای هر مهاجمی هستند
- آن‌ها پورت‌های باز روی یک سیستم و نوع سیستم را شناسایی می‌کنند که امکان متمرکزکردن حمله را فراهم می‌سازد
- بیشتر برنامه‌های اینترنتی از TCP یا UDP استفاده می‌کنند:

| پروتکل | ویژگی |
|---|---|
| **TCP** | اتصال‌گرا — ترتیب حفظ می‌شود و در صورت نیاز مجدداً ارسال می‌شود |
| **UDP** | بدون اتصال — «ارسال کن و امیدوار باش برسد» |

**ساختار لایه‌ها:**

```
Application Data
    TCP / UDP
       IP
 Data Link (Ethernet, Wi-Fi)
```

---

## ۵. پورت‌های TCP و UDP

- TCP و UDP هر دو دارای پورت هستند: یک فیلد در هدرهای TCP و UDP
- مجموع **۶۵,۵۳۶ (ضربدر ۲) پورت** وجود دارد
- پورت ۰ نامعتبر است؛ هر بسته با پورت ۰ باید دراپ شود
- Port Scanner‌ها بسته‌ها را به پورت‌های مختلف ارسال می‌کنند تا مشخص کنند چه سرویسی در حال گوش دادن است:
  - یافتن TCP 80 → وب‌سرور
  - یافتن TCP 445 → Windows Server Message Block
  - یافتن UDP 53 → DNS Server
  - و موارد دیگر
- **اما اینها همه می‌توانند تغییر کنند!**

> **نکتهٔ آزمون:** پورت‌های پیش‌فرض ثابت نیستند — مدیران شبکه می‌توانند سرویس‌ها را روی پورت‌های غیرمعمول پیکربندی کنند تا بهانه‌ای برای مخفی‌سازی از اسکنرهای ساده ایجاد کنند؛ این به خودی خود امنیت واقعی نیست (Security through Obscurity).

## ۶. انواع اسکن Nmap

| نوع اسکن | گزینه | توضیح |
|---|---|---|
| **Ping or ARP** | `-sn` | غیرفعال‌کردن اسکن پورت برای Host Discovery؛ اگر در همان LAN باشید از ARP استفاده می‌شود |
| **TCP connect** | `-sT` | اسکن پورت TCP با استفاده از اتصالات TCP معمولی |
| **TCP SYN** | `-sS` | اسکن پورت TCP با استفاده از اتصالات TCP نیمه‌باز (Half-Open) |
| **UDP** | `-sU` | اسکن پورت UDP (اغلب غیرقابل‌اعتماد) |
| **Version** | `-sV` | در ترکیب با سایر اسکن‌ها برای شناسایی سرویس‌ها از طریق پروب‌های فعال |

## ۷. اسکریپت‌های NSE در Nmap

**Nmap Scripting Engine (NSE):** شناسایی اطلاعات میزبان و آسیب‌پذیری‌ها.

| آرگومان NSE | عملکرد |
|---|---|
| `-sC` | اجرای اسکریپت‌های پیش‌فرض برای ارزیابی هدف |
| `--script all` | اجرای تمام اسکریپت‌ها روی هدف (می‌تواند به DoS منجر شود) |
| `--script-updatedb` | به‌روزرسانی اسکریپت‌های NSE (نیازمند دسترسی اینترنت) |
| `--script banner` | اجرای اسکریپت نام‌گذاری‌شده (*banner*) روی هدف‌ها |
| `--script-help "http*"` | نمایش راهنما برای اسکریپت‌های نام‌گذاری‌شده (از wildcard `*` برای همهٔ اسکریپت‌ها استفاده کنید) |
| `--script "http*"` | اجرای تمام اسکریپت‌های شروع‌شده با http روی هدف‌ها |
| `--script "smb*"` | اجرای تمام اسکریپت‌های شروع‌شده با smb روی هدف‌ها |

## جمع‌بندی نهایی

| مفهوم | نکتهٔ کلیدی |
|---|---|
| هدف Nmap | نقشه‌برداری شبکه + اسکن پورت؛ روی Linux، macOS و Windows اجرا می‌شود |
| Sweeping | ارسال ICMP Echo به بازهٔ IP برای کشف میزبان‌های فعال |
| `-sn` | فقط Host Discovery — اسکن پورت انجام نمی‌دهد |
| TCP vs UDP | TCP اتصال‌گرا، UDP بدون اتصال |
| تعداد پورت‌ها | ۶۵,۵۳۶ TCP + ۶۵,۵۳۶ UDP — پورت ۰ نامعتبر |
| `-sT` | TCP Connect Scan — اتصال کامل |
| `-sS` | TCP SYN Scan — Half-Open، مخفیانه‌تر |
| `-sU` | UDP Scan — اغلب غیرقابل‌اعتماد |
| `-sV` | Version Detection — شناسایی سرویس |
| NSE | موتور اسکریپت‌نویسی Nmap برای شناسایی اطلاعات و آسیب‌پذیری‌ها |

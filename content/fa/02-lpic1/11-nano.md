# شروع کار با ویرایشگر Nano

Nano یکی از **ساده‌ترین و دوست‌داشتنی ویرایشگرهای متنی** برای مبتدیان است. برخلاف Vi که دارای منحنی یادگیری تند است، Nano **کلیدهای میانبر واضح و شهودی** دارد که مستقیماً روی صفحه نمایش داده می‌شوند.

Nano برای مبتدیانی که می‌خواهند **سریع فایل‌ها را ویرایش کنند** بدون نیاز به **فقط حفظ دستورات** پیچیده‌ی Vi، انتخاب عالی است.

> **خلاصه‌ی کلیدی:** **`nano filename`** برای باز کردن فایل، **`Ctrl+X`** برای خروج، **`Ctrl+O`** برای ذخیره، **`Ctrl+W`** برای جستجو، **`Ctrl+A`** برای ابتدای خط، **`Ctrl+E`** برای انتهای خط. تمام کلیدهای میانبر در **پایین صفحه نمایش داده می‌شوند**.

## باز کردن Nano

### ایجاد یا ویرایش فایل

```bash
$ nano filename.txt
```

### صفحه‌ی Nano

```text
GNU nano 2.9.8                File: example.txt

This is line 1
This is line 2
~
~
^G Get Help   ^O WriteOut  ^R Read File  ^Y Prev Page  ^K Cut Text
^X Exit       ^J Justify   ^W Where Is   ^V Next Page  ^U Uncut Text
```

- **بالای صفحه:** نام ویرایشگر و نام فایل
- **وسط:** محتوای فایل
- **پایین:** کلیدهای میانبر

## کلیدهای میانبر اساسی

| کلید | توضیح |
|------|--------|
| **Ctrl+X** | خروج از Nano |
| **Ctrl+O** | ذخیره‌ی فایل (WriteOut) |
| **Ctrl+W** | جستجو (Where Is) |
| **Ctrl+A** | رفتن به ابتدای خط |
| **Ctrl+E** | رفتن به انتهای خط |
| **Ctrl+Y** | رفتن یک صفحه به‌بالا (Previous Page) |
| **Ctrl+V** | رفتن یک صفحه به‌پایین (Next Page) |
| **Ctrl+K** | حذف خط (Cut) |
| **Ctrl+U** | Paste کردن |
| **Ctrl+J** | Justify (فرمت‌بندی) |
| **Ctrl+^** | علامت‌گذاری متن (Mark) |
| **Ctrl+D** | حذف کاراکتر جریان |
| **Ctrl+H** | Backspace (حذف قبلی) |

## مثال عملی

### ایجاد فایل جدید

```bash
$ nano myfile.txt
```

صفحه‌ی خالی برای تایپ:
```
GNU nano 2.9.8                File: myfile.txt

(اکنون می‌توانید متن تایپ کنید)



^G Get Help   ^O WriteOut  ^R Read File  ^Y Prev Page  ^K Cut Text
^X Exit       ^J Justify   ^W Where Is   ^V Next Page  ^U Uncut Text
```

### تایپ متن

```bash
Hello World
This is my first Nano file
Nano is easy to use
```

### ذخیره‌ی فایل

```bash
Ctrl+O          # دستور Save
```

پرسش برای نام فایل:
```
Save as: myfile.txt
```

شما می‌توانید نام جدیدی وارد کنید یا Enter فشار دهید برای استفاده از نام فعلی.

### خروج

```bash
Ctrl+X          # خروج
```

اگر تغیری ذخیره نشده باشد:
```
Save modified buffer before exiting?
Y Yes  N No
```

- **Y:** ذخیره و خروج
- **N:** خروج بدون ذخیره

## جستجو و جایگزینی

### جستجو برای کلمه

```bash
Ctrl+W          # جستجو (Where Is)
```

وارد کنید:
```
Search: (enter your search term)
```

### یافتن نتیجه‌ی بعدی

```bash
Ctrl+W          # دوباره فشار دهید
```

## ویرایش متن

### حذف خط

```bash
Ctrl+K          # حذف تمام خط جریان
```

### Undo

متاسفانه، Nano **Undo ساده ندارد**. لازم است **احتیاط کنید** هنگام حذف.

### Copy و Paste

```bash
Ctrl+^          # علامت‌گذاری شروع
(حرکت کردن برای انتخاب متن)
Ctrl+K          # حذف (Cut)
(حرکت کردن به جای دیگر)
Ctrl+U          # Paste
```

## فایل‌های موجود

### باز کردن فایل موجود

```bash
$ nano /etc/hosts
```

Nano فایل را نمایش می‌دهد:
```
127.0.0.1   localhost
192.168.1.1 router.local
```

### ذخیره‌ی فایل موجود

```bash
Ctrl+O          # ذخیره
```

Nano نام فعلی فایل را نشان می‌دهد:
```
Save as: /etc/hosts
```

اگر فایل اصلی را می‌خواهید تغییر دهید، فقط **Enter** فشار دهید.

## گزینه‌های خط فرمان

```bash
$ nano -B filename       # Backup فایل اصلی ایجاد کن
$ nano -c filename       # شماره‌ی ستون و خط نمایش دهید
$ nano -m filename       # فعال کردن پشتیبانی موس
$ nano -w filename       # Wrap کردن خطوط طولانی غیرفعال
```

## نکات مفید

### رنگ‌آمیزی نحو (Syntax Highlighting)

Nano می‌تواند برخی فایل‌ها را **به‌طور خودکار رنگ‌آمیزی کند**:
- فایل‌های `.sh` (Shell scripts)
- فایل‌های `.c` (C code)
- فایل‌های `.conf` (Config files)

### Nano vs Vi

| ویژگی | Nano | Vi |
|--------|------|-----|
| **آسان برای مبتدیان** | ✓ بسیار | ✗ سخت |
| **کلیدهای واضح** | ✓ بالا | ✗ پنهان |
| **جستجو و جایگزینی** | △ ساده | ✓ قدرتمند |
| **Undo** | ✗ محدود | ✓ خوب |
| **سرعت** | ✓ خوب | ✓✓ بسیار سریع |
| **دسترس** | △ اکثر | ✓✓ همه‌جا |

## مسائل رایج و حل آن‌ها

### مشکل: نمی‌دانم فایل ذخیره شد یا نه

**حل:** عنوان صفحه نمایش تغییر می‌کند. اگر `*` (ستاره) کنار نام فایل باشد، یعنی **تغییری ذخیره نشده** است.

### مشکل: اتفاقی خط را حذف کردم

**حل:** متاسفانه Nano فقط **آخرین حذف** را می‌تواند بازگرداند. از `Ctrl+U` استفاده کنید.

### مشکل: نمی‌توانم متن را جستجو کنم

**حل:** از `Ctrl+W` استفاده کنید و کلمه‌ی جستجو را وارد کنید.

## نکات اصلاحی

### سوءتفاهم: Nano ضعیف‌تر است

**نه!** Nano برای **مبتدیان و کارهای سادگی** کاملاً کافی است. تنها **محدودیت** این است که **کمتر قدرتمند** از Vi برای ویرایش‌های پیچیده است.

> **نکته:** انتخاب بین Nano و Vi بستگی به **سطح تجربه** دارد. Nano برای **شروع** بهترین است.

## جمع‌بندی

Nano **ویرایشگری عالی برای مبتدیان** است که می‌خواهند:
- فایل‌ها را بدون پیچیدگی ویرایش کنند
- کلیدهای میانبر واضح و شهودی داشته باشند
- سریع و سادگی با کار شروع کنند

مرحله‌ی بعدی: اگر نیاز به ویژگی‌های پیشرفته دارید، **Vi را یاد بگیرید**. اما برای کارهای روزمره‌ی بسیاری، **Nano کاملاً کافی است**.

**Remember:** هر دو Nano و Vi ویرایشگرهای خوبی هستند. انتخاب شما **بستگی به ترجیح و نیاز** دارد.

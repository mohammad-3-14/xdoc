# شروع کار با ویرایشگر Vi

Vi یکی از **قدیمی‌ترین و قدرتمندترین ویرایشگرهای متنی** در جهان یونیکس/لینوکس است. اگرچه منحنی یادگیری آن تند است، اما یک‌بار که مهارت‌های پایه‌ای را یاد بگیرید، بسیار **سریع و کارآمد** خواهد شد.

Vi **در تمام سیستم‌های یونیکس‌مانند موجود** است، حتی روی سرورهای قدیمی‌ترین. این به معنای آن است که اگر **مهارت Vi را داشته باشید، می‌توانید در هر جایی کار کنید**.

درک Vi **اساسی برای هر مدیر سیستم لینوکس** است. این فصل تمام آنچه برای **شروع کار** لازم است را پوشش می‌دهد.

> **خلاصه‌ی کلیدی:** Vi دارای **سه حالت مختلف است**: **Command Mode** (برای دستورات)، **Insert Mode** (برای تایپ متن)، و **Ex Mode** (برای دستورات پیشرفته). **Escape** شما را به Command Mode برمی‌گرداند. **`i` یا `a`** شما را وارد Insert Mode می‌کند. **`:wq`** برای ذخیره‌ی فایل و خروج، **`dd`** برای حذف خط، **`yy`** برای کپی‌کردن است.

## سه حالت Vi

Vi **دارای سه حالت مختلف** است که هر کدام نقش‌های متفاوتی دارند:

### 1. Command Mode (حالت دستورات)

این **حالت پیش‌فرض** است وقتی Vi را باز می‌کنید. در این حالت:
- **هیچ متنی تایپ نمی‌شود**
- **دستورات اجرا می‌شوند** (حذف، کپی، جستجو و غیره)
- **هر کلید یک دستور است**

### 2. Insert Mode (حالت درج/تایپ)

در این حالت:
- **می‌توانید متن تایپ کنید**
- **سرعت متن درج می‌شود**
- **Escape برای برگشت به Command Mode**

### 3. Ex Mode (حالت اجرایی)

در این حالت:
- **دستورات پیشرفته اجرا می‌شود** (جستجو و جایگزینی، ذخیره‌ی فایل و غیره)
- **با `:` شروع می‌شود**

## باز کردن Vi

### باز کردن یک فایل موجود

```bash
$ vi filename.txt
```

### ایجاد فایل جدید

```bash
$ vi newfile.txt
```

اگر فایل موجود نباشد، Vi فایل خالی را باز می‌کند.

### صفحه‌ی اولیه‌ی Vi

```
~
~
~
~
~
~
~
~
"newfile.txt" [New File]
```

علامات `~` نشان‌دهنده‌ی خطوط خالی هستند. در بالای صفحه، نام فایل و وضعیت نمایش داده می‌شود.

## حالت Command Mode - دستورات بنیادی

### جابه‌جایی مکان‌نما

| دستور | توضیح |
|--------|--------|
| **h** | حرکت به‌چپ (یک کاراکتر) |
| **j** | حرکت به‌پایین (یک خط) |
| **k** | حرکت به‌بالا (یک خط) |
| **l** | حرکت به‌راست (یک کاراکتر) |
| **w** | حرکت به کلمه‌ی بعد |
| **b** | حرکت به کلمه‌ی قبلی |
| **0** | رفتن به ابتدای خط |
| **$** | رفتن به انتهای خط |
| **G** | رفتن به آخر فایل |
| **gg** | رفتن به ابتدای فایل |
| **:n** | رفتن به خط n (مثلا `:10`) |

### حذف متن

| دستور | توضیح |
|--------|--------|
| **x** | حذف کاراکتر جریان (زیر مکان‌نما) |
| **dd** | حذف تمام خط جریان |
| **dw** | حذف کلمه‌ی جریان |
| **d$** | حذف از مکان‌نما تا انتهای خط |
| **d0** | حذف از ابتدای خط تا مکان‌نما |

### کپی و Paste

| دستور | توضیح |
|--------|--------|
| **yy** | کپی‌کردن خط جریان (Yank) |
| **yw** | کپی‌کردن کلمه‌ی جریان |
| **p** | Paste کردن بعد از موقعیت جریان |
| **P** | Paste کردن قبل از موقعیت جریان |

### ویرایش سریع

| دستور | توضیح |
|--------|--------|
| **i** | ورود به Insert Mode (قبل از مکان‌نما) |
| **a** | ورود به Insert Mode (بعد از مکان‌نما) |
| **o** | ایجاد خط جدید (بعد از خط جریان) و ورود Insert Mode |
| **O** | ایجاد خط جدید (قبل از خط جریان) و ورود Insert Mode |
| **r** | جایگزینی کاراکتر جریان (فقط یک کاراکتر) |
| **R** | جایگزینی کاراکترهای متعدد (تا Escape) |

### جستجو

| دستور | توضیح |
|--------|--------|
| **/pattern** | جستجوی pattern به‌سمت پایین |
| **?pattern** | جستجوی pattern به‌سمت بالا |
| **n** | تکرار آخرین جستجو |
| **N** | تکرار آخرین جستجو (جهت معکوس) |

## حالت Insert Mode

### ورود به Insert Mode

```bash
i     # ورود قبل از مکان‌نما
a     # ورود بعد از مکان‌نما
o     # خط جدید و ورود
O     # خط جدید قبل و ورود
```

### تایپ متن

```bash
$ vi test.txt

(مکان‌نما روی خط اول)

i     # ورود Insert Mode

(اکنون می‌توانید متن تایپ کنید)

Hello World
This is Vi editor
```

### خروج از Insert Mode

```bash
Escape  # یا Ctrl+[
```

## حالت Ex Mode (سطح درجه‌بندی `:`)

حالت Ex برای دستورات **پیشرفته** استفاده می‌شود:

```bash
:w           # ذخیره‌ی فایل
:q           # خروج
:wq          # ذخیره و خروج
:q!          # خروج بدون ذخیره
:set number  # نمایش شماره‌ی خطوط
:%s/old/new/g  # جایگزینی تمام old با new
```

## ذخیره‌سازی و خروج

### ذخیره‌ی فایل بدون خروج

```bash
:w          # ذخیره‌ی فایل فعلی
:w newfile  # ذخیره‌ی فایل با نام جدید
```

### خروج

```bash
:q          # خروج (اگر تغیری نشده باشد)
:q!         # خروج بدون ذخیره
```

### ذخیره و خروج

```bash
:wq         # ذخیره و خروج
ZZ          # میانبر برای :wq
```

## نکات اصلاحی و دقیق‌تر

### سوءتفاهم: "Vi پیچیده است، من نمی‌توانم یاد بگیرم"

واقعی نیست! **دستورات پایه‌ی Vi ساده است**. شما نیاز دارید:
- **دستورات حرکت:** `h`, `j`, `k`, `l`
- **ورود Insert Mode:** `i`
- **خروج:** `Escape`, `:q`, `:wq`

این **5 دستور** برای شروع کافی‌اند. بقیه را می‌توانید **به‌تدریج یاد بگیرید**.

> **نکته‌ی اصلاحی:** شروع کار بسیار سادگی است. **تکرار و تمرین** مهارت را افزایش می‌دهد.

### سوءتفاهم: "موس کار نمی‌کند در Vi"

درست است. Vi **فقط کلیدبورد** استفاده می‌کند. این در واقع **مزیت است** زیرا:
- **سریع‌تر:** دستان شما در کلیدبورد باقی‌ می‌مانند
- **کارآمدتر:** بدون جابه‌جایی دست برای موس
- **از راه‌دور:** روی SSH کار می‌کند

> **نکته:** عدم استفاده از موس **به معنای کارآمدی بیشتر** است، نه مشکل!

### سوءتفاهم: "من باید دستورات را حفظ کنم"

**نه!** شما می‌توانید:
- **`:help` استفاده کنید:** `:help dd` برای کمک درباره‌ی `dd`
- **cheat sheet استفاده کنید:** تمام دستورات را چاپ کنید
- **تمرین کنید:** بیشتر دستورات را **یاد خواهید گرفت**

> **نکته:** تمرین منظم بهتر از حفظ است. **استفاده می‌کنید، یاد می‌گیرید.**

### سوءتفاهم: "Ex Mode دشوار است"

نه، اساسی است! فقط چند دستور مهم وجود دارد:
- `:w` - ذخیره
- `:q` - خروج
- `:wq` - ذخیره و خروج
- `:%s/old/new/g` - جایگزینی

> **نکته:** **Ex Mode شما را به دستورات پیشرفته رسانده می‌دهد** اما برای شروع فقط `:w` و `:q` کافی است.

## نصائح برای یادگیری Vi

1. **تمرین منظم:** روزی 15-20 دقیقه تمرین کنید
2. **یک فایل ساده‌ی متن درست کنید:** مثلاً فایل یادداشت شخصی
3. **دستورات کمی را یاد بگیرید:** بعد از هر کار، دستور دیگر‌ای یاد بگیرید
4. **Cheat sheet نزدیک نگهدارید:** برای مراجعه‌ی سریع
5. **دوستانتان با Vi کار می‌کنند را سوال کنید:** نکات مفیدی یاد می‌گیرید

## چند دستور مفید دیگر

```bash
u           # Undo - برگرداندن آخرین تغییر
Ctrl+r      # Redo - تکرار آخرین Undo
G           # رفتن به آخر فایل
gg          # رفتن به ابتدای فایل
5dd         # حذف 5 خط
```

## جمع‌بندی

Vi یک ویرایشگر قدرتمند است که نیاز به **تمرین و صبر** دارد. اما **یک‌بار یاد گرفتید، برای همیشه دانش دارید**.

مراحل یادگیری:
1. **اساسی:** `i`, `Escape`, `:w`, `:q`
2. **تکی:** حرکت، حذف، کپی‌کردن
3. **توسعه‌یافته:** جستجو، جایگزینی، اسکریپت‌ها

**Remember:** هیچ‌کس در روز اول با Vi ماهر نمی‌شود. **تکرار و صبر** کلید موفقیت است.

بعدی: **مهارت‌های پیشرفته‌ی Vi** و **آماده شدن برای امتحان LPIC-1**.

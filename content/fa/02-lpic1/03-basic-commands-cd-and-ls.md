# دستورات اساسی لینوکس — cd و ls

در هسته‌ی کار هر کاربر لینوکس در محیط خط فرمان (Terminal)، دو دستور اساسی و تقریباً هر‌روزه‌ی وجود دارد: `cd` برای تغییر دایرکتوری (پوشه) و `ls` برای نمایش محتویات دایرکتوری. این دو دستور به‌عنوان رفتار و برگشت در سیستم فایل‌های لینوکس نقش کلیدی دارند و درک عمیق آن‌ها برای مهارت‌های LPIC-1 ضروری است.

> **نکته اساسی:** درک صحیح مفهوم «دایرکتوری فعلی» (current working directory) و چگونگی جابه‌جایی در درخت‌های ریشه‌دار فایل‌سیستم، پایه‌ی تمام کارهای پیشرفته‌تر در خط فرمان است.

# معرفی محیط خط فرمان و فایل‌سیستم لینوکس

هر کاربری که وارد یک Shell (پوسته) لینوکسی می‌شود، اولاً در یک دایرکتوری خاص قرار می‌گیرد — این جا **دایرکتوری فعلی** نام‌گذاری می‌شود. فایل‌سیستم لینوکس یک ساختار درختی است: در ریشه (`/`)، دایرکتوری‌های اصلی مثل `/home`، `/etc`، `/var`، `/bin` و دیگران وجود دارند. هر دایرکتوری می‌تواند زیردایرکتوری‌های متعددی داشته باشد.

هنگامی که Shell راه‌اندازی می‌شود، معمولاً کاربر در دایرکتوری **home** خود قرار می‌گیرد (برای کاربر `abedini` مثلاً `/home/abedini`). برای انجام اکثریت کارها، باید بتوانی این مسیرها را تغییر دهی و محتویات دایرکتوری‌های مختلف را ببینی — دقیقاً اینجا است که `cd` و `ls` به‌کار می‌آیند.

# دستور ls — لیست‌کردن فایل‌ها و دایرکتوری‌ها

## معنای ls و کاربرد اساسی

دستور `ls` مخفف **list** است و ساده‌ترین و پرکاربردترین روش برای دیدن محتویات یک دایرکتوری است. وقتی بدون هیچ آپشن و آرگومانی اجرا می‌شود، فهرست فایل‌ها و زیردایرکتوری‌های دایرکتوری فعلی را نشان می‌دهد:

```bash
$ ls
Desktop       Documents     Downloads     Music        Pictures
Public        Templates     Videos        'VirtualBox VMs'    vmware
```

این خروجی ساده‌ترین شکل `ls` است. نام‌های فایل و دایرکتوری‌ها در یک ستون یا چند ستون نمایش داده می‌شوند (بسته‌ی به عرض ترمینال). اما این لیست ساده اطلاعات مفصلی مثل سایز فایل، تاریخ تغییر، یا پرمیشن‌های دسترسی را نشان نمی‌دهد.

## آپشن -l برای لیست تفصیلی (Long Format)

وقتی می‌خواهی اطلاعات بیشتری مثل اندازه فایل، تاریخ و ساعت آخرین تغییر، و سطح دسترسی ببینی، از آپشن `-l` استفاده می‌کنی:

```bash
$ ls -l
total 8
-rw-r--r-- 1 abedini abedini   4096 2025-12-03 23-02-54 'M abedini'   test
-rw-r--r-- 1 abedini abedini   2560 2025-12-03 23-13-11 '2025-12-03 23-02-54.mp4'
drwxr-xr-x 2 abedini abedini   4096 2025-12-03 10-07-43 Desktop
drwxr-xr-x 2 abedini abedini   4096 2025-12-03 22-21-30 Documents
drwxr-xr-x 2 abedini abedini   4096 2025-12-03 22-33-42 Downloads
```

هر ستون در این خروجی اطلاعات مختلفی را نشان می‌دهد:
- **ستون اول (پرمیشن‌ها):** مثلاً `-rw-r--r--` یا `drwxr-xr-x`
  - اولین کاراکتر: `-` برای فایل معمولی، `d` برای دایرکتوری
  - بقیه: دسترسی‌های خواندن (r)، نوشتن (w)، اجرا (x) برای صاحب، گروه، و دیگران
- **تعداد link‌ها**
- **صاحب فایل (Owner)**
- **گروه (Group)**
- **اندازه‌ی فایل (بایت)**
- **تاریخ و ساعت آخرین تغییر**
- **نام فایل یا دایرکتوری**

## آپشن -a برای نمایش فایل‌های پنهان

در لینوکس، هر فایل یا دایرکتوری که نام آن با نقطه (`.`) شروع شود، **فایل پنهان** تلقی می‌شود. این فایل‌ها معمولاً فایل‌های تنظیمی یا رفع‌خطای مربوط‌به اپلیکیشن هستند (مثلاً `.bashrc` یا `.ssh`). به‌طور پیش‌فرض، `ls` این فایل‌ها را نمایش نمی‌دهد. برای دیدن آن‌ها، از آپشن `-a` (all) استفاده کن:

```bash
$ ls -a
.              ..             .bashrc        .cache         .config
.local         Desktop        Documents      Downloads      Music
Pictures       Public         Templates      Videos         vmware
```

اینجا نقاط خاصی را مشاهده می‌کنی:
- `.` — دایرکتوری فعلی (خود)
- `..` — دایرکتوری والد (بالا‌تر در درخت)

این دو نقطه برای ناوبری در فایل‌سیستم بسیار مهم هستند (خصوصاً با `cd`).

## ترکیب آپشن‌ها: -la یا -al

اغلب می‌خواهی هم فایل‌های پنهان را ببینی و هم فرمت تفصیلی را داشته باشی. برای اینکار می‌توانی آپشن‌ها را ترکیب کنی:

```bash
$ ls -la
total 32
drwx------ 15 abedini abedini 4096 2025-12-03 23:02:54 .
drwxr-xr-x 23 root    root    4096 2024-11-01 15:30:15 ..
-rw-r--r--  1 abedini abedini  220 2023-08-01 09:15:42 .bashrc
drwx------  3 abedini abedini 4096 2025-12-02 14:22:33 .cache
drwx------  5 abedini abedini 4096 2025-11-28 18:45:21 .config
-rw-r--r--  1 abedini abedini 2048 2025-12-03 11:30:00 .ssh
drwxr-xr-x  2 abedini abedini 4096 2025-12-03 23-02-54 Desktop
drwxr-xr-x  2 abedini abedini 4096 2025-12-03 23-13-11 Documents
```

# دستور cd — تغییر دایرکتوری

## معنای cd و اهمیت آن

دستور `cd` مخفف **change directory** است و برای تغییر دایرکتوری فعلی (جایی که فعلاً قرار داری) به‌کار می‌رود. وقتی دستور `cd` اجرا می‌شود، Shell پوسته‌ی فعلی خود را به دایرکتوری جدید "جابه‌جا" می‌کند، و تمام دستورات بعدی نسبت به این دایرکتوری جدید اجرا می‌شوند.

## مسیرهای مطلق vs. نسبی

قبل از اینکه به مثال‌های عملی `cd` برویم، درک تفاوت بین مسیرهای **مطلق** و **نسبی** ضروری است:

| نوع مسیر | توضیح | مثال |
|---------|-------|------|
| **مسیر مطلق (Absolute Path)** | از ریشه فایل‌سیستم (`/`) شروع می‌شود و تا مقصد را کامل توضیح می‌دهد | `/home/abedini/Desktop` |
| **مسیر نسبی (Relative Path)** | نسبت به دایرکتوری فعلی توصیف می‌شود | `Desktop` یا `./Pictures` یا `../Documents` |

مسیرهای نسبی از سه نماد خاص استفاده می‌کنند:
- `.` — دایرکتوری فعلی
- `..` — دایرکتوری والد (یک سطح بالاتر)
- `~` — دایرکتوری خانه کاربر (معمولاً `/home/username`)

## مثال‌های عملی cd

### تغییر به دایرکتوری Desktop

اگر اکنون در `/home/abedini` هستی و می‌خواهی به `Desktop` برویی:

```bash
$ pwd
/home/abedini
$ cd Desktop
$ pwd
/home/abedini/Desktop
```

اینجا از **مسیر نسبی** استفاده کردیم. می‌توانستی به‌صورت مطلق نیز بنویسی:

```bash
$ cd /home/abedini/Desktop
```

### استفاده از .. برای رفتن به پوشه‌ی والد

اگر اکنون در `/home/abedini/Desktop` هستی و می‌خواهی به پوشه‌ی والد (یعنی `/home/abedini`) برویی:

```bash
$ pwd
/home/abedini/Desktop
$ cd ..
$ pwd
/home/abedini
```

می‌توانی از `..` مرات متعدد استفاده کنی تا چند سطح بالاتر رویی:

```bash
$ pwd
/home/abedini/Desktop/Projects/WebApp
$ cd ../../
$ pwd
/home/abedini
```

### تغییر به ریشه فایل‌سیستم

برای رفتن به ریشه (`/`):

```bash
$ cd /
$ pwd
/
$ ls
bin   boot   dev   etc   home   lib   media   mnt   opt   proc   root   run   sys   tmp   usr   var
```

اینجا دایرکتوری‌های اصلی لینوکس را مشاهده می‌کنی. هر یک منظور خاصی دارد:
- `/bin` — فایل‌های اجرایی دستورات اساسی
- `/etc` — فایل‌های تنظیمی سیستم
- `/home` — دایرکتوری‌های خانگی کاربران
- `/var` — فایل‌های متغیر (لاگ‌ها، ابطال‌ها و غیره)
- و دیگران...

### تغییر به دایرکتوری خانگی

برای بازگشت به دایرکتوری خانگی (home directory)، می‌توانی از تیلد `~` استفاده کنی:

```bash
$ cd /var/log
$ pwd
/var/log
$ cd ~
$ pwd
/home/abedini
```

یا به‌سادگی `cd` را بدون آرگومان اجرا کن:

```bash
$ cd
$ pwd
/home/abedini
```

### ناوبری در مسیرهای عمیق

فرض کن دایرکتوری ساختار زیر را داری:

```
/home/abedini/
├── Desktop/
├── Documents/
│   └── Projects/
│       └── Python/
│           └── DataAnalysis/
└── Downloads/
```

برای رفتن به `DataAnalysis` از مسیر نسبی:

```bash
$ cd Documents/Projects/Python/DataAnalysis
$ pwd
/home/abedini/Documents/Projects/Python/DataAnalysis
```

یا از مسیر مطلق:

```bash
$ cd /home/abedini/Documents/Projects/Python/DataAnalysis
```

## رفتار cd در خطاها

اگر سعی کنی به دایرکتوری‌ای برویی که وجود ندارد یا دسترسی به آن ندارید، Shell خطا می‌دهد:

```bash
$ cd /nonexistent
bash: cd: /nonexistent: No such file or directory
```

در این‌صورت، دایرکتوری فعلی تغییر نمی‌کند و Shell جایی که بود می‌ماند.

# سناریو کاربردی — جستجو و ناوبری در فایل‌سیستم

فرض کن می‌خواهی یک فایل پروژه پیدا کنی و در آن کار کنی. مراحل معمول:

1. **شروع از دایرکتوری خانگی و دیدن محتویات:**

```bash
$ cd ~
$ pwd
/home/abedini
$ ls
Desktop       Documents     Downloads     Music        Pictures
Public        Templates     Videos        vmware
```

2. **رفتن به Documents و بررسی پوشه‌ها:**

```bash
$ cd Documents
$ ls -l
total 12
drwxr-xr-x 3 abedini abedini 4096 2025-12-03 15:22:30 Projects
drwxr-xr-x 2 abedini abedini 4096 2025-11-20 10:15:45 Research
-rw-r--r-- 1 abedini abedini 2048 2025-12-01 14:30:21 notes.txt
```

3. **ورود به پوشه‌ی Projects:**

```bash
$ cd Projects
$ ls
WebApplication    DataAnalysis    Scripts
```

4. **بررسی فایل‌های پنهان در پوشه‌ی WebApplication:**

```bash
$ cd WebApplication
$ ls -la
total 24
drwxr-xr-x  4 abedini abedini 4096 2025-12-03 18:45:22 .
drwxr-xr-x  3 abedini abedini 4096 2025-12-03 15:22:30 ..
-rw-r--r--  1 abedini abedini  215 2025-12-01 12:30:00 .gitignore
drwxr-xr-x  8 abedini abedini 4096 2025-12-02 09:15:33 .git
-rw-r--r--  1 abedini abedini 1024 2025-12-02 16:45:12 README.md
drwxr-xr-x  2 abedini abedini 4096 2025-12-03 11:20:00 src
```

5. **بازگشت به محل قبلی و رفتن به پوشه‌ی دیگر:**

```bash
$ cd ../../
$ pwd
/home/abedini/Documents
$ cd ../Downloads
$ pwd
/home/abedini/Downloads
```

# نکات اصلاحی و سوءتفاهم‌های رایج

## cd فقط برای تغییر دایرکتوری فعلی است

یکی از ابهام‌های متداول این است که کاربران جدید فکر می‌کنند `cd` فایل‌ها را کپی یا منتقل می‌کند. **خیر**؛ `cd` فقط **دایرکتوری کاری Shell را تغییر می‌دهد**. فایل‌های قبلی در جای خود باقی می‌مانند.

## آپشن‌های `ls -l` و `ls -a` کاملاً مستقل هستند

بسیاری فکر می‌کنند که `-l` خود به خود فایل‌های پنهان را پنهان می‌کند یا نشان می‌دهد. اما واقعیت این است که این دو آپشن به‌طور مستقل کار می‌کنند:
- `ls -l` → فایل‌های عادی در فرمت طولانی
- `ls -a` → فایل‌های عادی + فایل‌های پنهان (فرمت کوتاه)
- `ls -la` → فایل‌های عادی + پنهان + فرمت طولانی

## `..` و `.` دایرکتوری‌های خقیقی نیستند

`.` و `..` نقاط ویژه‌ی فایل‌سیستم هستند که **مرجع** دایرکتوری‌ها را نشان می‌دهند، نه دایرکتوری‌های واقعی با محتوای خود. وقتی `cd ..` اجرا می‌کنی، Shell از این مرجع استفاده می‌کند تا به والد برود.

## مسیر نسبی vs. مطلق — هر دو صحیح هستند

بسیاری فکر می‌کنند که باید **همیشه** از مسیرهای مطلق استفاده کنند. اما هر دو معتبر هستند:
- **مطلق:** همیشه از ریشه شروع می‌شود، بدون تفاوت کجا هستی
- **نسبی:** کوتاه‌تر است و زماندار کمتری می‌برد اگر قبلاً در همسایگی دایرکتوری مقصد باشی

انتخاب بین آن‌ها بر اساس موقعیت و راحتی است.

# جمع‌بندی

دستورات `cd` و `ls` دو ستون اساسی کار در خط فرمان لینوکس هستند. `ls` به تو این اجازه می‌دهد که محتویات دایرکتوری‌ها را ببینی — از فایل‌های ساده تا فایل‌های پنهان و اطلاعات تفصیلی مثل سطح دسترسی و تاریخ. `cd` به تو این توانایی را می‌دهد که در درخت فایل‌سیستم لینوکس ناوبری کنی، چه با مسیرهای مطلق و چه نسبی.

تسلط بر این دو دستور نه‌تنها برای LPIC-1 ضروری است، بلکه پایه‌ی کار روزمره‌ی هر مسئولِ سیستم یا مهندسِ DevOps است. با تمرین، استفاده از `cd` و `ls` به‌طور خودکار و طبیعی می‌شود، و تو بدون تفکر در سیستم فایل‌های لینوکسی ناوبری خواهی کرد.

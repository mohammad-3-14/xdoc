# متغیرها و محیط‌های آن‌ها در لینوکس

متغیرها یکی از بنیادی‌ترین مفاهیم در برنامه‌نویسی و استفاده از سیستم‌های یونیکس‌مانند است. در سیستم‌عامل لینوکس، متغیرها نقش اساسی در عملکرد Shell و برنامه‌های مختلف ایفا می‌کنند. از تنظیم رفتار سیستم گرفته تا نگهداری اطلاعات موقت، متغیرها به ما اجازه می‌دهند تا محیط کار خود را سفارشی کنیم و برنامه‌هایی بنویسیم که با اطلاعات پویا کار کنند.

درک عمیق متغیرها و انواع مختلف آن‌ها (محلی در مقابل سراسری) برای هر کسی که می‌خواهد در امتحان LPIC-1 موفق شود یا در خط فرمان لینوکس کار کند، بسیار مهم است. این فصل تمام آنچه که لازم است بدانید را پوشش می‌دهد.

> **خلاصه‌ی کلیدی:** متغیرها **مکان‌های ذخیره‌سازی اطلاعات** هستند که در Bash با **علامت تساوی (`=`)** تعریف می‌شوند و با **علامت دلار (`$`)** و دستور **`echo`** نمایش داده می‌شوند. متغیرها به دو دسته **محلی (Local)** و **سراسری/محیطی (Global/Environment)** تقسیم می‌شوند. دستور **`export`** یک متغیر محلی را به سراسری تبدیل می‌کند، و دستور **`env`** تمام متغیرهای محیطی را نمایش می‌دهد.

## تعریف و درک متغیرها

### متغیر چیست؟

متغیر درواقع یک **نام رمزی (Symbolic Name)** برای یک **مقدار داده (Data Value)** است. وقتی شما یک متغیر را تعریف می‌کنید، Shell آن مقدار را در حافظه ذخیره می‌کند و هر زمان که نام آن متغیر را استفاده کنید، Shell به جای نام، آن مقدار ذخیره‌شده را جایگزین می‌کند.

متغیرها اغراض متفاوتی دارند:
- **ذخیره‌سازی اطلاعات:** نام‌ها، مسیرها، تنظیمات
- **انتقال اطلاعات بین برنامه‌ها:** محیط‌های سراسری که تمام برنامه‌ها می‌توانند دسترسی داشته باشند
- **کنترل رفتار Shell و برنامه‌ها:** تنظیمات سیستم و کاربردی
- **استفاده در اسکریپت‌ها:** ذخیره نتایج دستورات و محاسبات

### نحوه تعریف متغیر در Bash

در Bash، تعریف متغیر بسیار ساده است. فرمت کلی به‌شرح زیر است:

```bash
variable_name=value
```

**نکات مهم:**
- هیچ فاصله‌ای نباید بین نام، علامت تساوی و مقدار وجود داشته باشد
- نام متغیر باید با حرف یا خط تیره شروع شود (نه عدد)
- نام متغیر می‌تواند حروف، اعداد و خط تیره باشد
- بزرگ و کوچک حروف متفاوت است (`name` و `Name` دو متغیر مختلف هستند)

```bash
$ name=abedini
$ city=tehran
$ count=42
$ message="Hello World"
```

### نمایش مقدار متغیر

برای نمایش مقدار یک متغیر، از علامت دلار (`$`) قبل از نام متغیر استفاده می‌کنید:

```bash
$ name=abedini
$ echo $name
abedini

$ echo $city
tehran

$ echo "نام من $name است"
نام من abedini است
```

### دستور `env` برای نمایش تمام متغیرها

دستور `env` تمام **متغیرهای محیطی (Environment Variables)** را نمایش می‌دهد:

```bash
$ env
SHELL=/bin/bash
SESSION_MANAGER=local/Mabedini:@/tmp/.ICE-unix/1685,unix/Mabedini:/tmp/.ICE-unix/1685
XDG_SESSION_PATH=/org/freedesktop/DisplayManager/Session0
COLORTERM=truecolor
GNOME_TERMINAL_SCREEN=/org/gnome/Terminal/screen/6118ab91_2b6c_4945_aa9d_fc307656cd0e
GNOME_TERMINAL_SERVICE=:1.383
TERM=xterm-256color
USER=abedini
GNOME_TERMINAL_SERVICE=:1.383
DISPLAY=:0
SHLVL=1
XDG_VTNR=7
XDG_SESSION_ID=1
XDG_RUNTIME_DIR=/run/user/1000
GTK_MODULES=xapp-gtk3-module
XDG_SEAT=seat0
PWD=/var
LOGNAME=abedini
HOME=/home/abedini
LANG=en_US.UTF-8
... (و متغیرهای دیگری)
```

## متغیرهای محلی (Local Variables)

متغیر **محلی** متغیری است که تنها در **Shell فعلی** در دسترس است. اگر یک Shell فرزند ایجاد کنید (بای اجرای دستور `bash`، مثلاً)، آن متغیر محلی به Shell فرزند منتقل نمی‌شود.

### نمونه عملی: متغیر محلی

```bash
$ name=abedini
$ echo $name
abedini

$ bash
$ echo $name
(هیچ خروجی)
$ exit
$ echo $name
abedini
```

در این مثال:
1. در Shell اصلی، `name=abedini` تعریف می‌کنیم
2. مقدار آن را با `echo $name` نمایش می‌دهیم → `abedini`
3. یک Shell فرزند ایجاد می‌کنیم با `bash`
4. در Shell فرزند، `echo $name` هیچ خروجی ندارد (متغیر وجود ندارد)
5. Shell فرزند را خاتمه می‌دهیم با `exit`
6. دوباره در Shell اصلی متغیر وجود دارد

| اصطلاح | تعریف | دسترسی |
|--------|-------|---------|
| **متغیر محلی** | فقط در Shell فعلی | تنها Shell فعلی و توابع آن |
| **متغیر محیطی** | صادرشده (exported) | Shell فعلی + تمام Shell‌های فرزند |

## متغیرهای سراسری/محیطی (Global/Environment Variables) و `export`

متغیر **سراسری** یا **محیطی** متغیری است که توسط دستور **`export`** صادرشده و به تمام **Shell‌های فرزند** منتقل می‌شود. این متغیرها بخشی از **محیط (Environment)** نام‌برده می‌شوند.

### دستور `export`

برای تبدیل یک متغیر محلی به سراسری، از دستور `export` استفاده می‌کنید:

```bash
export variable_name=value
```

یا اگر متغیر قبلاً تعریف شده است:

```bash
variable_name=value
export variable_name
```

### نمونه عملی: تفاوت بین محلی و صادرشده

```bash
$ name=abedini
$ echo $name
abedini

$ bash
$ echo $name
(هیچ خروجی - متغیر محلی است)
$ exit

$ export name
$ bash
$ echo $name
abedini
(اکنون متغیر صادرشده است و در Shell فرزند قابل دسترس است)
$ exit
```

### نمایش متغیرهای صادرشده

```bash
$ env | grep name
name=abedini

$ env
... (تمام متغیرهای صادرشده)
name=abedini
...
```

## جدول مقایسه‌ای: محلی در مقابل سراسری

| ویژگی | محلی | سراسری (Exported) |
|--------|------|----------|
| **تعریف** | `variable=value` | `export variable=value` یا `variable=value; export variable` |
| **دسترسی در Shell فعلی** | ✓ دسترس | ✓ دسترس |
| **دسترسی در Shell فرزند** | ✗ ندسترس | ✓ دسترس |
| **دسترسی به برنامه‌های دیگر** | ✗ ندسترس | ✓ دسترس |
| **نمایش با `env`** | ✗ نمایش نمی‌شود | ✓ نمایش می‌شود |
| **پاک شدن** | وقتی Shell خاتمه یابد | وقتی Shell خاتمه یابد |

## متغیرهای محیطی مهم و پراستفاده

سیستم‌عامل لینوکس و Bash از **متغیرهای محیطی از پیش‌تعریف‌شده** استفاده می‌کند که نقش‌های خاصی دارند. درک این متغیرها برای کار موثر با خط فرمان ضروری است.

### متغیر `HOME`

**نقش:** مسیر دایرکتوری خانگی (Home Directory) کاربر را نگهداری می‌کند.

```bash
$ echo $HOME
/home/abedini

$ cd $HOME
$ pwd
/home/abedini
```

### متغیر `USER`

**نقش:** نام کاربر فعلی را نگهداری می‌کند.

```bash
$ echo $USER
abedini

$ whoami
abedini
```

### متغیر `SHELL`

**نقش:** Shell پیش‌فرض کاربر را نگهداری می‌کند.

```bash
$ echo $SHELL
/bin/bash
```

### متغیر `PWD`

**نقش:** مسیر دایرکتوری فعلی (Present Working Directory) را نگهداری می‌کند.

```bash
$ cd /var
$ echo $PWD
/var

$ cd /home
$ echo $PWD
/home
```

### متغیر `PATH`

**نقش:** **مجموعه‌ای از مسیرهایی که Shell در آن‌ها به دنبال برنامه‌های اجرایی می‌گردد.**

PATH یکی از مهم‌ترین متغیرهای محیطی است. وقتی شما یک دستور را تایپ می‌کنید (مثلاً `ls` یا `echo`)، Shell در دایرکتوری‌های مشخص‌شده در PATH به دنبال آن دستور می‌گردد. اگر فایل اجرایی در یکی از این مسیرها پیدا شود، آن اجرا می‌شود.

```bash
$ echo $PATH
/usr/local/bin:/usr/bin:/bin:/usr/local/games:/usr/games:/usr/local/sbin:/usr/sbin:/sbin
```

مسیرها با **کولون (`:`)** جدا می‌شوند. ترتیب مهم است: Shell دایرکتوری‌ها را به ترتیب جستجو می‌کند.

#### افزودن مسیر جدید به PATH

```bash
$ export PATH=$PATH:/home/abedini/mycommands

$ echo $PATH
/usr/local/bin:/usr/bin:/bin:/usr/local/games:/usr/games:/usr/local/sbin:/usr/sbin:/sbin:/home/abedini/mycommands
```

### متغیر `SHLVL`

**نقش:** سطح تودرتویی Shell‌ها (Shell Level) را نگهداری می‌کند.

```bash
$ echo $SHLVL
1

$ bash
$ echo $SHLVL
2

$ bash
$ echo $SHLVL
3
```

هر بار که یک Shell فرزند ایجاد کنید، `SHLVL` یک واحد افزایش می‌یابد.

### متغیر `PS1`

**نقش:** **فرمت Prompt اصلی (Primary Shell Prompt) را کنترل می‌کند.**

PS1 متغیری است که شامل کدهای خاصی است که تعیین می‌کند Prompt (علامت `$`) چگونه نمایش داده شود. مثلاً می‌تواند نام کاربر، نام میزبان و مسیر فعلی را نمایش دهد.

```bash
$ echo $PS1
\[\e]0;\u@\h: \w\a\]$(debian chroot)\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\$
```

این کد پیچیده شامل کدهای ANSI برای رنگ‌آمیزی و فرمت‌کردن Prompt است.

#### تغییر Prompt

```bash
$ PS1="$ "
$ echo "سلام"
سلام
$

$ PS1="[\u@\h:\w]\$ "
[abedini@Mabedini:/var]$ pwd
/var
[abedini@Mabedini:/var]$
```

### متغیر `EDITOR`

**نقش:** ویرایشگر پیش‌فرض سیستم را نگهداری می‌کند.

برنامه‌های بسیاری این متغیر را برای باز کردن فایل‌ها به ویرایش استفاده می‌کنند.

```bash
$ export EDITOR=nano
$ export EDITOR=vim
```

### متغیر `LANG` و `LC_*`

**نقش:** **زبان و تنظیمات محلی (Locale) سیستم را کنترل می‌کند.**

```bash
$ echo $LANG
en_US.UTF-8

$ export LANG=fa_IR.UTF-8
$ export LANG=en_US.UTF-8
```

## جدول خلاصه‌ای: متغیرهای محیطی مهم

| متغیر | مثال | نقش |
|-------|--------|------|
| **HOME** | `/home/abedini` | دایرکتوری خانگی |
| **USER** | `abedini` | نام کاربر |
| **SHELL** | `/bin/bash` | Shell پیش‌فرض |
| **PWD** | `/home/abedini` | دایرکتوری فعلی |
| **PATH** | `/usr/bin:/bin:...` | مسیرهای جستجوی برنامه‌ها |
| **SHLVL** | `1`, `2`, `3` | سطح تودرتویی Shell |
| **PS1** | `$ ` یا `user@host:path$ ` | فرمت Prompt |
| **EDITOR** | `vim` یا `nano` | ویرایشگر پیش‌فرض |
| **LANG** | `en_US.UTF-8` | زبان و Locale |
| **TERM** | `xterm-256color` | نوع Terminal |

## مثال‌های عملی

### ایجاد و استفاده از متغیرها در اسکریپت

```bash
#!/bin/bash

# تعریف متغیرهای محلی
name="Mohammad"
age=30
city="Tehran"

# استفاده از متغیرها
echo "نام: $name"
echo "سن: $age"
echo "شهر: $city"
echo "سلام، $name! شما $age ساله هستید و در $city زندگی می‌کنید."
```

### افزودن دایرکتوری شخصی به PATH

```bash
$ mkdir -p ~/mybin
$ echo '#!/bin/bash' > ~/mybin/greet
$ echo 'echo "سلام، $1!"' >> ~/mybin/greet
$ chmod +x ~/mybin/greet

$ export PATH=$PATH:~/mybin
$ greet Mohammad
سلام، Mohammad!
```

### تغییر Prompt برای آسان‌تر شدن کار

```bash
$ PS1="[\u@\h \W]$ "
[abedini@Mabedini ~]$ cd /var
[abedini@Mabedini var]$ 

$ PS1="\033[01;32m[\u@\h]\033[00m \w$ "
[abedini@Mabedini] /var$
```

## جریان متغیرها و ارثبری (Variable Inheritance)

هنگامی که یک Shell فرزند ایجاد می‌شود، **تنها متغیرهای صادرشده (exported)** به آن منتقل می‌شوند:

```text
Shell اصلی (PID: 1000)
├─ متغیر محلی: name="abedini" (تنها اینجا)
└─ متغیر صادرشده: export city="tehran" (منتقل می‌شود)
   │
   └─ Shell فرزند (PID: 1001)
      ├─ نمی‌تواند به name دسترسی داشته باشد
      └─ می‌تواند به city دسترسی داشته باشد
```

### نمایش فرایند

```bash
$ name="local"
$ export city="tehran"

$ bash -c 'echo $name $city'
 tehran
```

توجه کنید که `name` نمایش داده نشد (خالی است)، اما `city` نمایش داده شد.

## نکات اصلاحی و دقیق‌تر

### سوءتفاهم: فاصله‌های اضافی در تعریف متغیر

یک اشتباه رایج این است که کاربران فاصله‌هایی را قبل یا بعد از علامت تساوی اضافه می‌کنند. این کار باعث خطا می‌شود:

```bash
$ name = abedini
bash: name: command not found

$ name= abedini
bash: abedini: command not found

$ name=abedini  # صحیح
$ echo $name
abedini
```

**دلیل:** Shell علامت فاصله را **جدا‌کننده دستورات** در نظر می‌گیرد، نه بخشی از تعریف متغیر.

> **نکته‌ی اصلاحی:** تعریف متغیر باید **بدون فاصله** بین نام، علامت تساوی و مقدار باشد: `variable=value`، نه `variable = value`.

### سوءتفاهم: بزرگ و کوچک حروف

متغیرها **حساس به بزرگ و کوچک حروف** هستند. این یک منبع بسیار رایج از اشتباهات است:

```bash
$ Name=Ali
$ echo $name
(هیچ خروجی)

$ echo $Name
Ali
```

**convention معمولی:**
- متغیرهای محلی کوچک هستند: `name`, `count`
- متغیرهای محیطی بزرگ هستند: `HOME`, `USER`, `PATH`

> **نکته‌ی اصلاحی:** متغیرها **حساس به بزرگ و کوچک حروف** هستند. `$name` و `$Name` و `$NAME` سه متغیر مختلف هستند.

### سوءتفاهم: `export` تغییرات را برای Shell والد منتقل نمی‌کند

یک باور غلط رایج این است که اگر یک متغیر را در Shell فرزند تغییر دهید و صادر کنید، آن تغییر به Shell والد منتقل خواهد شد. این صحیح نیست:

```bash
$ x=1
$ bash
$ export x=2
$ echo $x
2
$ exit

$ echo $x
1  # هنوز 1 است، نه 2
```

تغییرات Shell فرزند **هیچ تاثیری بر Shell والد ندارند**.

> **نکته‌ی اصلاحی:** متغیرها و تغییرات آن‌ها **تنها یک طرفه** منتقل می‌شوند (والد به فرزند)، نه برعکس.

### سوءتفاهم: `$` در جلوی نام متغیر هنگام تعریف

هنگام تعریف متغیر، نباید از علامت دلار استفاده کنید:

```bash
$ $name=abedini
bash: : command not found

$ name=abedini  # صحیح
```

علامت دلار تنها هنگام **خواندن** مقدار متغیر استفاده می‌شود، نه هنگام تعریف:

```bash
x=10
y=$x  # صحیح: y را برابر مقدار x کنید
echo $y
10
```

> **نکته‌ی اصلاحی:** علامت دلار (`$`) تنها هنگام **مراجعه به مقدار** متغیر استفاده می‌شود، نه هنگام **تعریف** یا **تخصیص**.

## جمع‌بندی

متغیرها عنصری جدایی‌ناپذیر از کار با Shell لینوکس هستند. آن‌ها ابزاری قدرتمند برای ذخیره اطلاعات، کنترل رفتار سیستم و نوشتن اسکریپت‌های مؤثر هستند. درک تفاوت بین **متغیرهای محلی** (که تنها در Shell فعلی موجود هستند) و **متغیرهای صادرشده** (که به Shell‌های فرزند منتقل می‌شوند) یکی از مهم‌ترین دروس است.

به یاد داشته باشید که:
- متغیرها با **`variable=value`** تعریف می‌شوند (بدون فاصله)
- مقادیر با **`$variable`** خوانده می‌شوند
- دستور **`export`** متغیرها را به فرزندان منتقل می‌کند
- دستور **`env`** تمام متغیرهای محیطی را نمایش می‌دهد
- متغیرهایی مانند `PATH`, `HOME`, `SHELL`, `PS1` نقش‌های خاصی دارند

این مهارت‌ها پایه‌های لازم برای مراحل پیشرفته‌تر مثل نوشتن اسکریپت‌های پیچیده (shell scripting) و مدیریت سیستم هستند. هر چه بیشتر با متغیرها کار کنید، آن‌ها برای شما طبیعی‌تر خواهند شد.

مبحث بعدی **عملگرهای Shell (Shell Operators)** و **دستورات شرطی (Conditional Statements)** را پوشش خواهد داد، جایی که متغیرها نقش بسیار مهمی ایفا می‌کنند.

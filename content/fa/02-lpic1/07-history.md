# تاریخچه دستورات و مدیریت History در لینوکس

درهر جلسه‌ی کاری با Shell لینوکس، شما دستورات زیادی اجرا می‌کنید. بسیاری از این دستورات مشابه یا یکسان هستند. اگر بتوانید به دستورات قبلی‌تان دسترسی داشته باشید و آن‌ها را مجدداً استفاده کنید، کار بسیار سریع‌تر و کارآمدتر خواهد شد. این دقیقاً کاری است که دستور **`history`** انجام می‌دهد.

تاریخچه Shell (History) یکی از ویژگی‌های قدرتمند Bash است که بسیاری از کاربران جدید آن را نادیده می‌گیرند. درک عمیق نحوه کار با history می‌تواند بهره‌وری شما را به‌طور قابل‌ملاحظه‌ای افزایش دهد. این فصل تمام آنچه‌ی لازم است بدانید را پوشش می‌دهد.

> **خلاصه‌ی کلیدی:** دستور **`history`** **تمام دستورات قبلی اجرا‌شده را نمایش می‌دهد** که هریک دارای **شماره ترتیبی** است. می‌توانید با **`!number`** آن دستور را **مجددا اجرا** کنید، یا از **`!string`** برای **جستجوی دستورات شامل رشته** استفاده کنید. **جستجوی معکوس** با **`Ctrl+R`** امکان جستجوی تاریخچه را فراهم می‌کند.

## تاریخچه Shell چیست؟

تاریخچه Shell (History) یک **لیستی از تمام دستورات** است که کاربر در جلسه‌ی فعلی (یا جلسات قبلی) اجرا کرده است. Shell این دستورات را در حافظه نگهداری می‌کند و می‌تواند آن‌ها را بعداً برای مشاهده یا مجددا اجرا کردن بازیابی کند.

### مکان ذخیره‌سازی History

تاریخچه دستورات معمولاً در فایل **`~/.bash_history`** ذخیره می‌شود:

```bash
$ ls -la ~/.bash_history
-rw-r--r-- 1 abedini abedini 28570 Dec  4 01:03 /home/abedini/.bash_history
```

### اهمیت History

- **کاهش تایپ:** دستورات طولانی یا پیچیده‌ای که قبلاً اجرا کرده‌اید را نمی‌تواند دوباره تایپ کنید
- **بازیابی دستورات:** دستوری را یادتان رفت؟ history در کمک است
- **خودکارسازی:** اسکریپت‌ها می‌توانند از تاریخچه استفاده کنند
- **آموزش:** تاریخچه نشان‌دهنده‌ی شیوه‌ی کار شما است

## دستور `history` - نمایش تاریخچه

### استفاده‌ی ساده

```bash
$ history
    1  cd /home
    2  ls -la
    3  pwd
    4  echo "سلام"
    5  cat /etc/hostname
    ...
  320  echo $SHELL
  321  bash
  322  exit
  323  env
  324  history
```

هر خط شامل **شماره ترتیبی** و **دستور** است.

### نمایش N دستور آخر

```bash
$ history 10
   315  abedini@192.168.220.131
   316  id
   317  exit
   318  id
   319  exit
   320  env
   321  exit
   322  bash
   323  exit
   324  echo $name
   325  history 10
```

### نمایش تاریخچه با grep

```bash
$ history | grep ssh
   303  ssh root@192.168.220.131
   304  ssh abedini@192.168.220.131
   305  ssh test@192.168.220.128
   311  ssh abedini@192.168.220.131

$ history | grep "echo"
   324  echo $name
   330  echo $PATH
   331  echo $EDITOR
   332  history
```

## مجددا اجرای دستورات از History

### استفاده‌ی `!!` برای اجرای آخرین دستور

```bash
$ echo "سلام جهان"
سلام جهان

$ !!
echo "سلام جهان"
سلام جهان
```

### استفاده‌ی `!number` برای اجرای دستور خاص

```bash
$ history | tail -5
   320  pwd
   321  ls -la
   322  echo $HOME
   323  cat /etc/hostname
   324  history

$ !322
echo $HOME
/home/abedini
```

### استفاده‌ی `!string` برای جستجو و اجرا

اجرای آخرین دستوری که با رشته‌ی مشخص شروع می‌شود:

```bash
$ history | grep ssh
   303  ssh root@192.168.220.131
   304  ssh abedini@192.168.220.131

$ !ssh
ssh abedini@192.168.220.131
(اتصال SSH ایجاد می‌شود)

$ !ec
echo $HOME
/home/abedini
```

### استفاده‌ی `!?string?` برای جستجو در هر جای دستور

```bash
$ history | grep PATH
   330  echo $PATH
   
$ !?PATH?
echo $PATH
/usr/local/bin:/usr/bin:/bin:...
```

## جستجوی معکوس (Reverse Search)

یکی از قدرتمندترین ویژگی‌های history، **جستجوی معکوس** است که با فشار **`Ctrl+R`** فعال می‌شود:

```bash
(reverse-i-search)`': _
```

```bash
$ Ctrl+R
(reverse-i-search)`ssh': ssh abedini@192.168.220.131
```

سپس می‌توانید:
- **Enter** را فشار دهید تا دستور اجرا شود
- **Ctrl+R** را دوباره فشار دهید تا نتیجه‌ی قبلی‌ پیدا شود
- **Escape** را فشار دهید تا از حالت جستجو خارج شوید

## دستور `fc` - ویرایش و اجرای دستورات

دستور **`fc`** (Fix Command) اجازه می‌دهد تا دستورات قبلی را ویرایش و مجددا اجرا کنید:

```bash
$ fc 320
(ویرایشگر پیش‌فرض باز می‌شود با دستور 320)

$ fc -l 315 320
   315  id
   316  exit
   317  pwd
   318  ls -la
   319  echo $HOME
   320  cat /etc/hostname
```

## مدیریت و کنترل History

### حذف History

```bash
$ history -c  # پاک کردن تاریخچه‌ی جلسه‌ی فعلی (حافظه)
$ history -w  # نوشتن تاریخچه در فایل ~/.bash_history
```

### محدودیت تعداد دستورات

```bash
$ echo $HISTSIZE
1000

$ export HISTSIZE=500  # محدود کردن به 500 دستور
```

### متغیرهای مرتبط

| متغیر | نقش |
|-------|------|
| `HISTSIZE` | تعداد دستورات ذخیره‌شده در حافظه |
| `HISTFILESIZE` | تعداد دستورات ذخیره‌شده در فایل ~/.bash_history |
| `HISTFILE` | مسیر فایل history |
| `HISTCONTROL` | کنترل کردن کدام دستورات ذخیره شوند |
| `HISTTIMEFORMAT` | فرمت نمایش زمان در history |

## History Expansion

### عملگرهای History

| عملگر | نقش |
|-------|------|
| `!!` | آخرین دستور |
| `!n` | دستور شماره‌ی n |
| `!-n` | n دستور‌های قبل از آخرین دستور |
| `!string` | آخرین دستوری که با string شروع می‌شود |
| `!?string?` | آخرین دستوری که شامل string است |
| `^old^new^` | جایگزینی old با new در آخرین دستور |

### مثال: جایگزینی در آخرین دستور

```bash
$ echo "salam"
salam

$ ^salam^hello^
echo "hello"
hello
```

## نمونه‌های عملی

### جستجو و اجرای دستور SSH

```bash
$ history | grep ssh
   305  ssh root@192.168.220.128

$ !ssh
ssh root@192.168.220.128
(اتصال SSH ایجاد می‌شود)
```

### مشاهده‌ی دستورات اخیر با timestamp

```bash
$ export HISTTIMEFORMAT="%Y-%m-%d %H:%M:%S: "
$ history | tail -5
  2025-12-04 01:03:47: pwd
  2025-12-04 01:05:12: ls -la
  2025-12-04 01:07:30: echo $HOME
  2025-12-04 01:08:45: cat /etc/hostname
  2025-12-04 01:10:00: history
```

### اجرای دستوری از N مدت قبل

```bash
$ history | tail -20 | grep curl
   315  curl https://example.com

$ !curl
curl https://example.com
(درخواست HTTP ارسال می‌شود)
```

## نکات اصلاحی و دقیق‌تر

### سوءتفاهم: تغییری در دستور بعد از `!string`

زمانی که از `!string` استفاده می‌کنید، Shell **دقیقاً همان دستور را اجرا می‌کند** بدون اینکه پرسائید:

```bash
$ history | grep echo
   324  echo "سلام"

$ !echo
echo "سلام"
سلام
(دستور فوری اجرا می‌شود)
```

اگر می‌خواهید قبل از اجرا تغییری دهید، از `!:p` برای **نمایش** بدون اجرا استفاده کنید:

```bash
$ !echo:p
echo "سلام"
(فقط نمایش می‌دهد، اجرا نمی‌کند)
```

> **نکته‌ی اصلاحی:** `!string` **فوری دستور را اجرا می‌کند**. برای نمایش بدون اجرا، از `:p` استفاده کنید.

### سوءتفاهم: جایگزینی در history expansion

زمانی که از `^old^new^` استفاده می‌کنید، **فقط اولین رخداد** جایگزین می‌شود:

```bash
$ echo "apple apple"
apple apple

$ ^apple^orange^
echo "orange apple"
orange apple
(فقط اول جایگزین شد)
```

برای جایگزینی همه موارد، دستور را دوباره تایپ کنید یا از `:gs/old/new/` استفاده کنید.

> **نکته‌ی اصلاحی:** جایگزینی در history expansion **تنها رخداد اول را تغییر می‌دهد**.

### سوءتفاهم: History در Subshell منتقل نمی‌شود

History **تنها در Shell اصلی** ذخیره می‌شود. اگر Shell فرزند ایجاد کنید، history منتقل نمی‌شود:

```bash
$ history | wc -l
325

$ bash
$ history | wc -l
0
(Shell فرزند history خالی دارد)

$ exit
```

> **نکته‌ی اصلاحی:** History **تنها در Shell اصلی** دسترس است، نه در Shell‌های فرزند.

## جمع‌بندی

تاریخچه Shell یکی از ابزارهای قدرتمندی است که می‌تواند کار شما را به‌طور قابل‌ملاحظه‌ای سریع‌تر کند. یادگیری:
- **`history`** برای مشاهده‌ی دستورات قبلی
- **`!number`** برای اجرای دستور خاص
- **`!string`** برای جستجو و اجرای دستور
- **`Ctrl+R`** برای جستجوی معکوس
- **`!!`** برای آخرین دستور

این مهارت‌ها کار با Shell را بسیار کارآمدتر می‌کند و بخشی از عادات یک کاربر باتجربه‌ی لینوکس هستند.

موضوع بعدی **دستور `man` برای دریافت کمک و مستندات** است، که همراه با history، شما را قادر می‌سازد تا بیشتر مستقل‌تر کار کنید.

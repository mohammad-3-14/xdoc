# xDoc

Welcome to my personal documentation site. This is where I keep notes, snippets, and
references I come back to often — Vue and Nuxt patterns, PHP/WHMCS hook recipes, Docker
workflows, and security checklists.

Use the sidebar to browse by category, or press **Ctrl+K** (**⌘K** on macOS) to search.

## Sections

- **Frontend** — Vue.js and Nuxt notes, patterns, and gotchas.
- **Backend** — PHP and WHMCS hook development notes.
- **DevOps** — Docker and deployment notes.
- **Security** — Practical security checklists and reminders.

This site is bilingual (Persian/English) and fully static — generated with Nuxt Content v3.
